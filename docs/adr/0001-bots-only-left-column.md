# ADR-0001：左栏只列机器人，没有对话列表

- 状态：已采纳（2026-10-15 被 [ADR-0014](0014-cloud-claude-code.md) 修订：左栏顶部可以切换「机器人｜Claude Code」，机器人那边仍然只放机器人）
- 日期：2026-10-10（导航收敛 2026-10-14 再次确认）
- 相关：DESIGN.md §19、§21、§42、§57

## 背景

上游 ChisaBot 是企业「AI 同事」平台：左栏是频道、对话列表、团队 Bot、记忆等入口。ChisaBot 是一个人的私人助手，用户要求
左栏只列机器人（2026-10-10），打开应用直接面对机器人，没有首页、没有「新聊天」。

## 决定

- 左栏 = 搜索 + 机器人列表（主机器人置顶）+「＋」新建机器人。不列对话。
- 每个（用户, 机器人）有一个「当前对话」，所有设备共用（§42）；要换话题用机器人 ⋯ 菜单的「新话题」，旧对话在「历史对话」里。
- 打开应用进入上次用的机器人。

## 后果

- 概念少：用户只需要理解「机器人」。
- 历史对话不在左栏一眼可见，靠 ⋯ →「历史对话」。
- IM 来的对话不进历史对话列表（它们属于 IM 会话）。
