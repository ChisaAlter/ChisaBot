# CB-004 — 机器人详情改成标签窗格

日期：2026-10-14

## 之前

机器人资料的主路径是中间一页（`/bots/$agentId`）：头像和一段角色说明，然后是「模型设置」下拉，再往下叠「已暂停 / 通知 / 发消息 / 重置 / 删除」，再加上活动和「更新去哪里」。聊天旁边另有一块较简的资料卡（去聊天、管理、面板、电脑、删除），和中间那页不是同一个东西。

左栏「⋯」能打开详情，但也会跳到那页中间的资料。

## 之后

同一块窗格用在两处：

- 聊天右侧（窄窗口里是抽屉）：和左栏同一张头像、同一行字（名称、职责、私有/公开），下面用设置页的分段开关切 **详情 / 资料库 / 电脑**。
- 还没有对话的机器人：`/bots/$agentId` 画同一块窗格，不再铺那叠设置卡。已经有对话的，这个地址会打开该对话并带上详情窗格。

**详情**先是正在做的事和例行任务（没有例行任务时是一句「请在聊天中设置例行任务。」）。模型、暂停、通知、面板、重置、删除收进下面一张「运行」卡。账号级的「不在时，更新去哪里」默认折起。

**资料库**只列这个机器人写下的记忆和它的记忆来源，并链到全部记忆。

**电脑**列出账号下的设备；在对话里还可以打开计算机画面。

左栏菜单按现有能力收成单行：置顶、重命名、复制对话 ID、从侧边栏隐藏，然后才是详情、计算机、新话题、面板、电脑操作、主机器人、恢复、删除。没有做「移至新分组」和「标为未读」——机器人没有分组，也没有标未读的接口。

网页、安装成应用的桌面窗口、手机窄屏共用这一块。宽窗口是聊天旁的栏，放不下时走原来的右侧抽屉。

## 外观

信息架构仍是三个分区和收拢后的设置。外观用 ChisaBot 已有的零件，不另画一套：

- 身份行和左栏机器人行相同：`ChannelAvatar`（36）、`glass-item-t` / `glass-item-s`。私有、公开、系统写在副标题里，不是胶囊标签。
- 三个分区是设置页的 `sg-segmented`。右栏「面板 | 计算机」也是这套控件，另外有一块只适合两段的滑动底；这里不复制那块底，也不做通栏下划线。
- 「运行」、资料、例行任务是现有的 `PageRows` / `Item`，节标题用 `sh-title`。通知用现有的 `Select`。没有对话时，返回用现有的 `Button`。

没有居中大头像，也没有为这一块新写焦点环或间距。

## 和 CB-003 的重叠

没有改创建机器人向导，也没有改全局焦点样式。这一块不再给标签或「不在时」另加 `focus-visible` 类，焦点走按钮、分段开关和行自己的样式。
