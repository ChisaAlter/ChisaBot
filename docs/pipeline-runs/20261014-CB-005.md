## Root cause

1. **Sync reconnect after every local turn**: `useConversationSync` sets `rebase` on `onRunFinalized`. The next activity poll, if the server `running` bit is still true for a few hundred ms, called `join()` / `connectAgent` again. Message nodes remount; `content-visibility` loses remembered heights (falls back to 240px) then expands → viewport shows older history, then stick-to-bottom springs back.
2. **content-visibility selector**: `:nth-last-child(-n+6)` counted the loading cursor and queued-message stack as siblings, so streaming (cursor on) pushed a real message into the cold zone.
3. **Smooth stick-to-bottom resize** made any height thrash visible as jump-then-slide.

## Fix

- `shouldCatchRunningOnRebase`: only connect for `running` on rebase when there is no previous activity (first open).
- CSS: `content-visibility` only on `[data-message-id]:not(:nth-last-child(-n + 8 of [data-message-id]))`; `overflow-anchor: none` on StickToBottom scroller.
- CopilotChat `scrollView={{ resize: "instant", initial: "instant" }}`.
