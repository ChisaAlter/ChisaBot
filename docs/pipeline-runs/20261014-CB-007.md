# CB-007 PC 自动更新追上内部 0.2.x

时间：2026-10-14 CST

## 问题
用户桌面 ChisaBot PC 仍是内部测试版 **0.2.4**（`C:\软件\ChisaBotPC`）。公开频道最新曾是 **0.1.8**；`electron-updater` 默认 `allowDowngrade=false`，把 0.1.8 当成降级，不下载。feed / `latest.yml` / setup 资产本身正常。

## 处理
- 不打开 `allowDowngrade`。
- 正式版抬到 **0.3.0**（> 0.2.4）：根 `package.json`、`pc/package.json`、Android `versionName` + `versionCode` 214、Helm `appVersion`、desktop Cargo 一并对齐。
- 发版分支 `release/publish/v0.3.0`，合并后打 tag / GitHub Release；Client release 上传 `latest.yml` + setup，使 0.2.4 看到升级。

## 结果
见协调侧 `/workspace/ChisaBot/pipeline-runs/20261014-CB-007.md`（发版完成后回填 tag / Client run / `latest.yml` version）。
