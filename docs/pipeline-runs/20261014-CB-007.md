# CB-007 PC 自动更新追上内部 0.2.x

时间：2026-10-14 CST

## 问题
用户桌面 ChisaBot PC 仍是内部测试版 **0.2.4**。公开频道最新曾是 **0.1.8**；`electron-updater` 默认 `allowDowngrade=false`，把 0.1.8 当成降级，不下载。feed / `latest.yml` / setup 资产本身正常。

## 处理
- 不打开 `allowDowngrade`。
- 正式版抬到 **0.3.0**（> 0.2.4）：根 `package.json`、`pc/package.json`、Android `versionName` + `versionCode` 214、Helm `appVersion`、desktop Cargo 一并对齐。
- 发版分支 `release/publish/v0.3.0` → PR #91，合并 `03a0a0a`；手动打 tag `v0.3.0`（Publish/GHCR 仍可能被 Magpie 基线挡住，与 0.1.7/0.1.8 相同）。
- Client release run **38526350371** 成功：上传 `latest.yml` + setup。

## 结果
- https://github.com/ChisaAlter/ChisaBot/releases/tag/v0.3.0
- `latest.yml` version **0.3.0**（> 0.2.4）；path `ChisaBot-PC-0.3.0-x64-setup.exe`
- 残留内部 0.2.x 安装版可自动追上公开频道。
