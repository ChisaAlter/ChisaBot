# CB-003 — Create Bot is one step, and fields do not glow blue

Date: 2026-10-14

## Before

Creating a robot was a three-step wizard:

1. Name, responsibility, and role, prefilled with the finance examples 「报销助手」「财务」「核对发票、给费用分类、整理报销单」.
2. 「谁可以看到它？」— private or public.
3. 「它在哪里运行？」— built-in, or a self-hosted AG-UI endpoint and optional bearer key.

A focused text field drew a blue halo (`box-shadow` plus a blue border) from the shared focus styles. The same halo showed on web, and on the desktop and Android shells that load those styles or copy them for login.

## After

Creating a robot is one dialog: name, responsibility, and role, all starting empty, with generic placeholders and no finance example. **创建机器人** saves it on this server as a private coworker. There is no visibility step and no runtime or endpoint step. An empty endpoint is what the API already treats as the in-process Bot; the role text is the prompt it runs on.

Focused inputs, text areas, selects, checks, and switches no longer paint that blue ring. Focus is a slightly stronger edge (and, for a check or switch, a neutral outline) so the keyboard still shows where it is. The web sheet covers the desktop and Android webviews. The PC login sheet, the Android login assets, and the auth-web login page use the same edge instead of the blue halo.

Editing an existing coworker can still change visibility. Remote AG-UI agents stay a package (`agents.yaml`) concern, not part of this form.

The same dialog can take a portrait before create. It uses the account avatar cropper (square, 256×256 JPEG). The picture is sent as `avatarSeed` on `POST /api/agents` and stored in the existing seed column; a missing picture still uses the new id as the generated face. A short forged seed is ignored. The left rail and the empty chat show that portrait.

## Style

The create sheet uses the same dialog chrome as settings, brand, and confirm: 22px padding, a 20px/600 title, a 12px description, `Field` / `FieldLabel` / `Input` / `Textarea`, and a right-aligned footer (`取消` outline, `创建机器人` primary). The portrait is a field labeled 头像. Empty, it is a 40px glass preview at the input radius (`--r-md`) plus the outline button. After a file is chosen, the crop stage uses that same glass and radius instead of the account dialog's centered pink-to-blue circle. The account profile cropper is unchanged. Focus on the name field stays an ink edge with no blue halo.
