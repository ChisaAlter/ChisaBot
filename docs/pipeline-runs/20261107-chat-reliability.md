# CB-114：聊天显示与模型回退修复

分支 `fix/chat-reliability`，基于 `9a00ed62`（0.1.137）。当前为未发布候选，正式服务和 Hermes 运行实例尚未更新。

## 已确认的原因

- 故障时主模型 SWE-2 在 30 秒无首段输出后被取消，随后调用已失效的备用模型，备用返回 404。原提示把这个错误归给用户所选主模型。当前目录仍有 `devin/swe-2`，配置的两个备用模型已不在目录；使用应用自己的连接解析入口直连该网关时，SWE-2 返回 HTTP 200 和正文，首段约 1.35 秒。这项只验证模型路由可用性，不是正式客户端验收。
- `TranscriptMessage` 把流式后续文本按 `step` 画为无气泡的过程行；普通 Markdown 达到标题与列表数量阈值后又被改写为 `doc`，改变格式和高度。
- 空闲回合仍可能建立弹性高度保留，折叠后多余高度成为空白。窄屏发送/失败卡追加时直接贴底曾出现单帧 130–158px 位移。

## 候选行为

- 当前完整目录过滤失效的显式备用项；目录为空、过期或不可读取时保留原配置。指定备用项全失效时只用主模型，不擅自选择别的供应商。Hermes 无备用时取消切换期限，仍保留模型请求自身的期限。
- 备用失败与工具结果未知分别提示；所有可见正文使用气泡，普通 Markdown 不自动转文档，代码围栏内部的指令保持原样；标题加代码块保留共同表面。
- 空闲回合不建立新的高度保留；新增消息和错误卡平滑跟底，减少动态效果模式照旧直接贴底。
