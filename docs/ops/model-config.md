# 模型配置运维

[← 运维手册总览](README.md)

模型的接入、选择器和切换逻辑见 [models.md](../models.md) 和 [magpie.md](../magpie.md)。本页是运维视角：**机器人能不能一直答得上话**。

## 1. 需要配置的几项

| 项                   | 在哪里配                                                       | 建议                                                           |
| -------------------- | -------------------------------------------------------------- | -------------------------------------------------------------- |
| 默认模型             | 设置 → 模型（管理员）                                          | 选一个有稳定额度的模型；免费模型常有每日额度                   |
| 备用模型（fallback） | 设置 → 模型 →「备用模型」，或 `PUT /api/admin/model-fallbacks` | 至少配 1–2 个**不同供应商**的备用，主模型 429 / 5xx 时自动切换 |
| 生图模型             | 设置 → 模型 → 生图模型（部署设置引用环境变量里的密钥）         | 「改图」= 以原图为主体参考重新生成                             |
| 识图                 | 默认跟随主模型；主模型不支持图片时单独配一个识图模型           | —                                                              |
| 首次启动模型         | `deploy/.env` 的 `BOT_PROVIDER`、`BOT_MODEL` 和对应地址 / 密钥 | 之后都在网页里改                                               |

模型密钥：管理员配置的存在数据库（用 `KEY_ENCRYPTION_KEY` 加密），环境变量里的放 `.env`（600）。都不进仓库。

## 2. 常用操作

```sh
# 看当前备用模型
curl -s 127.0.0.1:3001/api/admin/model-fallbacks
# 清空备用模型
curl -s -X PUT 127.0.0.1:3001/api/admin/model-fallbacks -H 'content-type: application/json' -d '{"models":[]}'
# 模型往返自检（不保存）
sh /opt/chisabot-updater/smoke.sh
```

（在宿主机上直连 `127.0.0.1:3001` 时走的是单管理员后端，不经网关登录；这些接口不要暴露到公网。）

改默认模型前记下旧值（或写一个小的回退脚本），出问题时能一步改回。

## 3. 常见问题

| 现象                                 | 原因                                                              | 处理                                                        |
| ------------------------------------ | ----------------------------------------------------------------- | ----------------------------------------------------------- |
| 机器人不回答、自检失败，日志里是 429 | 免费模型每日额度用完（有的要十几个小时才恢复）                    | 换默认模型或配备用模型；长期用付费 / 自托管模型             |
| 某些免费模型在官方客户端之外被拒绝   | 供应商限制只能在自家客户端里用                                    | 换模型                                                      |
| 选择器里看不到 Magpie 的模型         | 模型列表每 `MODEL_CATALOG_REFRESH_MINUTES`（默认 10）分钟同步一次 | 点「刷新」，见 [magpie.md](../magpie.md#配置顺序)           |
| 切换模型后正在跑的回复没变           | 运行快照：正在跑的一轮用开始时的模型                              | 下一轮生效，见 [models.md](../models.md#目录缓存和运行快照) |
| 更多排查                             | —                                                                 | [operations.md](../operations.md#模型问题排查)              |

## 4. 探测模型是否可用

不要在真实对话里试。用管理员自检（只测默认模型），或在**预览容器**里用一次性机器人逐个试候选模型（[preview.md](preview.md)）。
临时拷进容器的探测脚本用完删掉。
