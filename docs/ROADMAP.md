# ROADMAP（看板）

## 当前状态（核对至 2026-11-28 · `v0.1.194`）

ChisaBot 主线已完成以下核心工程闭环：

1. **DSH 主内核切换与聊天可靠性收口（`v0.1.138`–`v0.1.139`，CB-114 / CB-115）**：独立 DSH Host + PostgreSQL 自有会话运行层全面接管模型/工具循环，Android 切换为 Kotlin 壳 + 同源手机布局。
2. **个人助理生产交付与通知恢复（`v0.1.140`–`v0.1.142`，CB-116）**：ICS 日历、IMAP/SMTP 邮箱、每日晨报、任务成果核验、未知副作用对账、本人通知账本、Windows/macOS 通用版 Ed25519 更新验签及宿主机完整备份/恢复上线。
3. **连续操作与恢复体验迭代（`v0.1.143`，CB-117，PR #522 `a76570e8`）**：草稿/引用/IndexedDB 附件隔离恢复、流式快照合并写入、重连追平提示、活动任务分页与 PC 完整路径恢复落地。
4. **全面脱离 早期上游模板 印记、退役过渡内核与空表收尾（CB-118 / CB-016）**：完成 `0067` / `0068` 数据库自有命名迁移（`chisabot_local_*`、`chisabot_channel_mappings`，reader 4）与废弃空表清理（DROP），彻底移除旧 `/api/conversations（原旧兼容路由）` 路由、`旧前缀请求头` 头、Hermes / Intelligence / Mastra 过渡代码与过时英文文档；仅保留 `deploy/pin-resources.sh` 与数据库 `identity` 读取保障存量数据零丢失。
5. **多端能力跃升、全栈性能与四轴外观重设计（`v0.1.162`–`v0.1.192`，CB-131…CB-143）**：完成 ProkBot 全量对标 Wave 1–10（`v0.1.170`）、阶段感知实时插话与全链路流式提速（`v0.1.177`）、全栈性能优化与 PC 独立更新窗口（`v0.1.181`）、全站 UI 丝滑过渡（`v0.1.182`）、主题/背景画布/纯 CSS 三档材质四轴重设计（`v0.1.183`，彻底下线重型液态玻璃透镜）、多账号安全加固与 PC 语音增强（`v0.1.184`）、右边栏收起定位与 PC 小窗切大窗防撕裂修复（`v0.1.185`）、六套深度定制主题、自定义面板修复与深浅色平滑切换（`v0.1.186`）、精简模式、对话内连接卡片与 PC 自检/群聊收敛/MCP auto 模式 UI（`v0.1.187`）、无白边通透柔和磨砂质感恢复（`v0.1.188`）、输入框语音输入统一接入后台 ASR 与未配置隐藏（`v0.1.189`）、移除聊天直连子代理入口、增强任务卡片与上线后台无感电脑操控全链路（`v0.1.190`）、修复大图片/资料库上传 413 遮蔽与条件定时/云端浏览器接管/DSH 与安全护栏/Android 语音桥（`v0.1.191`），以及全量六模块审查优化（PR #599–#604）、输入框图片点击预览与对话弹跳根治及设置页切页秒开修复（PR #605，`v0.1.192`）。
