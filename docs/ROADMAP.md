# ROADMAP（看板）

## 当前状态（核对至 2026-11-11 · `v0.1.143` + 去上游印记与架构收尾）

ChisaBot 主线已完成以下核心工程闭环：

1. **DSH 主内核切换与聊天可靠性收口（`v0.1.138`–`v0.1.139`，CB-114 / CB-115）**：独立 DSH Host + PostgreSQL 自有会话运行层全面接管模型/工具循环，Android 切换为 Kotlin 壳 + 同源手机布局。
2. **个人助理生产交付与通知恢复（`v0.1.140`–`v0.1.142`，CB-116）**：ICS 日历、IMAP/SMTP 邮箱、每日晨报、任务成果核验、未知副作用对账、本人通知账本及宿主机完整备份/恢复上线。
3. **连续操作与恢复体验迭代（`v0.1.143`，CB-117，PR #522 `a76570e8`）**：草稿/引用/IndexedDB 附件隔离恢复、流式快照合并写入、重连追平提示、活动任务分页与 PC 完整路径恢复落地。
4. **全面脱离 早期上游模板 印记、退役过渡内核与空表收尾（CB-118 / CB-016）**：完成 `0067` / `0068` 数据库自有命名迁移（`chisabot_local_*`、`chisabot_channel_mappings`，reader 4）与废弃空表清理（DROP），彻底移除旧 `/api/conversations（原旧兼容路由）` 路由、`旧前缀请求头` 头、Hermes / Intelligence / Mastra 过渡代码与过时英文文档；仅保留 `deploy/pin-resources.sh` 与数据库 `identity` 读取保障存量数据零丢失。

这一页是项目总看板：每一项指向 [BACKLOG](BACKLOG.md) 中带验收标准的条目。完整版本记录见 [CHANGELOG](CHANGELOG.md)，功能全表见 [features.md](features.md)，日常交接与验证入口见 [HANDOFF.md](HANDOFF.md)。
